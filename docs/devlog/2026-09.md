## 2026-09-29 - Launch installed Workbench as a full host agent

### Result

- The installed Web and TUI launchers run DSH with the file sandbox disabled by
  default and keep the caller's XDG, Codex, and Claude homes, so the agent uses
  the machine's Git identity, signing, and GitHub CLI login without extra
  grants.
- In that default mode tool commands inherit the whole DSH environment,
  including the owner's DeepSeek credential, as with any host agent.

  governed every tool call.
