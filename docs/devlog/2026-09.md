# Development log - 2026-09

## 2026-09-25 - TypeScript is the primary source and test language

### Result

- Source and tests use TypeScript under a pinned compiler and Node type
  toolchain; stable JavaScript CLI entry points remain.
- The candidate moves to v0.1.0-rc.2 with Node >=24.3.0 as its runtime floor.

### Why / context

- The Workbench needs one checked development language for portable product
  code and its acceptance tests.
- Node 24.0 emitted an experimental type-stripping warning on the stable CLI;
  Node 24.3.0 runs the same CLI with clean stderr.

### Evidence

- Strict typecheck and all 16 tests passed with the frozen root lockfile;
  Node 24.3.0 CLI checks, public source scan, and CI are required before delivery.
